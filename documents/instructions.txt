Dependencies : 
sudo apt install libssl-dev
sudo pacman -S openssl #arch 


To compile:
Encryption:
gcc main.c queue.c thread.c globals.c encryption.c -o encryption -lssl -lcrypto

Server:
gcc server.c server_global.c serverThread.c socket_queue.c -o server

Client:
gcc client.c -o client

Monitor component:
gcc -Wall -Wextra -O2 monitor_component.c -o monitor_component

sudo ./monitor_component /home/folder/
